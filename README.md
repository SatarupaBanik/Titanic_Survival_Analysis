# Titanic_Survival_Analysis
This project performs a detailed exploratory data analysis (EDA) and builds a predictive model on the Titanic dataset to identify patterns that influenced passenger survival.
The goal is to apply EDA techniques to uncover patterns and build a logistic regression model to predict passenger survival.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load and clean the data
2. Visualize trends (Age, Gender, Pclass, Fare)
3. Handle missing values (age imputation, drop cabin)
4. Convert categorical features to numeric
5. Train a logistic regression model
6. Evaluate performance (accuracy: 82%)

## Highlights
- Found strong survival patterns across gender and class
- Imputed missing ages using class-based averages
- Achieved high prediction accuracy with a simple model
- Final insights presented in PDF format

## Deliverables
- Jupyter Notebook (`.ipynb`)
- PDF Report
- Readable, commented code with clean visualizations
